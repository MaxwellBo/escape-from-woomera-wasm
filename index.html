About this build

          

            Escape from Woomera (EFW Team, 2002–2004, demo v0.84) is a
            Half-Life (GoldSrc) mod widely cited as the first documentary video game.
            This page boots the original mod files — its three
            efw_prototype_level* maps and shipped assets — inside the
            open-source Xash3D-FWGS engine cross-compiled to WebAssembly, with
            game logic compiled to WASM from the open Half-Life SDK plus a
            port of the recovered v0.84 DLL overlay (decompile/).

Setup guide

          
    
            
  1. Wait for steps 1–2 (mod zip + vendored Uplink valve/ data). The engine then boots on its own.
    2. 
            
  2. If boot did not start, click Boot Woomera in WASM. It runs with -game woomera and loads efw_prototype_level1.
    3. 
            
  3. Click the game view once to capture the mouse (pointer lock) and send keyboard to the engine. Esc releases the mouse. A keyboard and mouse are required, as with the original. Press E or click a person to talk, I for the diary, [/] to turn pages.
    4. 
            
  4. If the screen stays black, open the engine log below the game and the browser console.
