Fair warning

            

              The mod's custom game code only ever shipped as Windows DLLs, so the
              browser runs its maps, models, textures and sounds on stock Half-Life
              game logic. You can walk the real Woomera compound, but scripted
              systems (hope meter, conversations) will be degraded or missing.
            

          

          

            
You need retail Half-Life

            

              Engine + mod ship here; the base-game valve/ data does not
              (copyrighted). Point step 2 at a Half-Life install (e.g. from Steam)
              containing valve/pak0.pak. Files stay on your machine and
              are copied into in-memory WASM storage for the session only.
            

          

        

      


      

        

          
About this build

          

            Escape from Woomera (EFW Team, 2002–2004, demo v0.84) is a
            Half-Life (GoldSrc) mod widely cited as the first documentary video game.
            This page boots the original mod files — its three
            efw_prototype_level* maps and shipped assets — inside the
            open-source Xash3D-FWGS engine cross-compiled to WebAssembly, with
            stock Half-Life game logic likewise compiled to WASM.

Setup guide

          
    
            
  1. Wait for step 1 to finish (mod assets unpack from the vendored zip).
    2. 
            
  2. Install Half-Life once (Steam) and click Select Half-Life folder, choosing the folder that contains valve/. Nothing is uploaded anywhere.
    3. 
            
  3. Click Boot Woomera in WASM. The engine starts with -game woomera and loads efw_prototype_level1.
    4. 
            
  4. Click the game view to capture mouse/keyboard. A keyboard and mouse are required, as with the original.
    5. 
            
  5. If the screen stays black, open the engine log below the game and the browser console — missing valve/ files are the usual cause.
    6.
