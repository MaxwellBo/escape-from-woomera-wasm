Fair warning

            

              The original EscapeFromWoomera.dll and
              client.dll are loaded by a 32-bit Windows build of
              Xash3D. Wine runs that build in the browser, so the mod is not
              decompiled. The web host has no OpenGL, so the engine uses its
              software renderer. Click the view, then use the mouse and
              WASD. Expect it to be slow: the CPU is interpreted.

About this build

          

            Escape from Woomera (EFW Team, 2002–2004, demo v0.84) is a
            Half-Life (GoldSrc) mod widely cited as the first documentary video game.
            This page boots the original Windows DLLs — not a
            decompile — inside a Windows build of Xash3D FWGS, under
            Wine (Boxedwine) in the browser.

Setup guide

          
    
            
  1. Wait for Wine and the Windows game zip. The first load is about 120 MB.
    2. 
            
  2. The engine starts on its own: xash3d.exe -game woomera -ref soft, then loads efw_prototype_level1.
    3. 
            
  3. Click the game view. The mouse is captured for looking around. WASD walks, E uses, the mouse buttons talk and fire. Esc releases the mouse.
    4. 
            
  4. If the view stays black, open the Wine log under the game.
    5.
